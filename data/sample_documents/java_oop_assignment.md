# CS201 — Java Programming Assignment 3
**Topic:** Object-Oriented Programming, Classes, and Objects  
**Course:** Advanced Object-Oriented Software Design  

## Assignment Overview
In this assignment, you will implement an object-oriented inventory management system using Java.

### Key Concepts Required:
1. **Classes and Objects**: Model real-world entities using well-encapsulated classes.
2. **Constructors and Methods**: Define instance methods and parameterised constructors.
3. **Inheritance & Polymorphism**: Create a hierarchy of base and derived classes.
4. **Encapsulation**: Private fields with public getters and setters.

### Task Specifications:
- Create a `Product` class with `id`, `name`, and `price`.
- Implement a subclass `ElectronicProduct` with `warrantyPeriodMonths`.
- Demonstrate polymorphism through the `calculateDiscount()` method.

Ensure all `.java` source files compile with Java JDK 17+.
